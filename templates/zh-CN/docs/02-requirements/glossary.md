# 术语表（Glossary）

> 本文是项目所有核心术语、缩写、实体名的**唯一权威来源**。其它文档使用术语时应与本文一致，不得自行引入同义词。
>
> 用途：避免 AI 跨文档时因术语漂移误判（如 Skill / Agent / Module / Capability 在不同文档里语义不同）。

## 使用规则

- 新增术语前先搜索本表是否已有同义词。
- 术语含义发生变化时，本表先更新；再扫描其它文档同步。
- 同义词、禁用别名必须显式列出，AI 会按"禁用别名"自动重写。
- 与 [`feature-registry.md`](../05-project/feature-registry.md) 的功能 ID（F-xxx）配合使用：术语描述"是什么"，feature 描述"做不做"。

## 维护规则

- 一个术语对应一行，不允许多行重复定义。
- 若一个概念在不同上下文有歧义，应拆分为两条独立术语并显式互相 disambiguate。
- 术语变更影响接口、数据模型或验收标准时，按 [`../../DOCS_MAINTENANCE.md`](../../DOCS_MAINTENANCE.md) §10.1 同步对应权威文档。
