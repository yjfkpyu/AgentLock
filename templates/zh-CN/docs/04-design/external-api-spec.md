# 外部 API 规范

## 用途

定义面向外部系统、交互层、集成方或设备配套软件暴露的接口边界。

## 建议章节

### 1. API 分类

- 查询接口
- 命令接口
- 订阅接口
- 若项目不是 HTTP / RPC 系统，可改写为：CLI 命令、消息主题、文件格式、串口协议、设备命令集或 IPC 接口

### 2. 接口模板

- 路径或主题
- 输入参数
- 返回结构
- 错误语义
- 权限要求

### 3. 版本与兼容性

- 版本策略
- 废弃流程

### 4. 适用边界

- 哪些接口属于正式对外契约
- 哪些接口仅限内部模块使用，不应写进本文

## 不应写入本层的内容

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
