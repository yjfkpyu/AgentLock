# 扩展能力描述文件规范（按需）

## 用途

定义扩展能力描述文件的结构、字段、加载约束与安全边界。

若项目使用 `SKILL.md`，可直接沿用；若项目使用插件清单、能力注册文件、任务声明文件或设备能力描述，也可把本文改写为对应格式规范。

## 建议章节

### 1. 文件结构

- 元数据区
- 说明区
- 执行区

### 2. 字段定义

- 名称
- 描述
- 触发条件
- 依赖项
- 版本 / 兼容性 / 权限要求（按需）

### 3. 解析规则

- 必填项
- 可选项
- 兼容处理

## 不应写入本层的内容

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
