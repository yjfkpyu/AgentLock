# 数据模型

## 用途

定义项目中的核心对象、语义关系、引用方式以及上下文或状态承载结构。

## 建议章节

### 1. 核心对象清单

- 每个对象的语义角色
- 对象之间的关联关系

### 2. 语义映射

- 外部数据如何映射到内部对象
- 关键枚举和状态值的定义原则

### 3. 上下文 / 状态对象（按需）

- 运行期上下文
- 持久化状态或长期记忆
- 检索、引用或关联恢复机制

如果项目没有“记忆”概念，可改写为配置、会话状态、设备状态、缓存态或执行上下文。

## 不应写入本层的内容

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
