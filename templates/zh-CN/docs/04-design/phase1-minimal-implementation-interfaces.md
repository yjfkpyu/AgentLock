# 阶段最小实现接口

## 用途

在正式进入实现前，冻结当前阶段必须成立的最小工程契约。

> “接口”不限于 HTTP / RPC。对不同项目，它也可以是模块边界、板级抽象、消息格式、驱动契约、文件格式、命令行参数或状态机约束。

## 建议章节

### 1. 当前阶段目标

- 当前阶段的最小闭环是什么

### 2. 必须冻结的接口

- 共享状态接口
- 审计接口
- 消息或事件接口
- 生命周期接口

### 3. 延后实现的内容

- 记录明确延期到后续阶段的能力

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
