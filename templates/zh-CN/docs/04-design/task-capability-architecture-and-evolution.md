# 任务 / 能力映射架构与演进机制（按需）

## 用途

定义需求语义与执行实现之间的能力映射层，避免直接把场景硬编码到流程里。

适用于存在“需求 -> 能力 -> 绑定 -> 执行”中间层的项目；如果项目结构较简单，可将本文并入总体架构或模块设计文档。

## 建议章节

### 1. 核心对象

- Capability / Function / Action
- Provider / Adapter / Module
- Binding
- Policy
- Gap

### 2. 能力解析流程

- 从任务、命令、事件或场景需求到能力集合
- 从能力集合到可执行绑定

### 3. 缺口与进化闭环

- 如何识别能力缺口
- 如何记录、优先级排序和回流到设计或实现

### 4. 探索阶段边界

- 哪些情况下需要受限探索
- 探索输出如何转回受控执行

## 不应写入本层的内容

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
