# 智能体规范

## 用途

定义项目中智能体或核心执行单元的职责、边界、生命周期和协作方式。

如果项目没有智能体、多执行单元或可独立编排的执行主体，可以不启用本文件，或将其改写为“执行单元规范”。

## 建议章节

### 1. 角色划分

- 主控角色
- 专项角色
- 工具代理角色

### 2. 生命周期

- 创建
- 激活
- 执行
- 挂起或恢复
- 终止

### 3. 能力装配

- 技能、工具、记忆、策略如何绑定

### 4. 协作边界

- 哪些任务可以自主处理
- 哪些任务必须升级、审批或移交

## 不应写入本层的内容

- 高层愿景、战略定位（属于 01-vision）
- 需求描述和用例定义（属于 02-requirements）
- 系统级架构边界（属于 03-architecture）
- 项目管控信息（属于 05-project）
- 开发规范和编码标准（属于 06-dev-guide）
