# 交互界面 / 操作面架构（按需）

## 用途

定义项目的人机交互面或操作面边界，例如 Web、App、Desktop、CLI、HMI、控制台或设备上位机界面。

如果项目完全没有人机交互层，可以不启用本文件。

## 建议章节

### 1. 交互目标

- 交互面承担什么职责
- 交互面不承担什么职责

### 2. 信息 / 操作结构

- 主要页面、命令空间、操作台或面板结构
- 导航层次或操作路径

### 3. 渲染与反馈策略

- 图形界面项目可写：SSR/CSR、实时更新、权限反馈
- CLI / HMI / 桌面项目可写：命令反馈、状态提示、告警、阻塞与恢复策略
