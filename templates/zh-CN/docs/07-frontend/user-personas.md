# 用户 / 操作者 / 集成方角色模型

## 用途

定义不同使用者、操作者、维护者或系统集成方的目标、权限、使用场景和操作差异。

## 建议章节

### 1. 角色分层

- 终端用户或业务操作角色
- 运维、审批、值守或维护角色
- 集成方、调用方或设备管理角色
- 管理角色或平台管理员

### 2. 每类角色说明

- 主要任务
- 关注指标
- 权限边界
- 常见操作频率
- 如果项目没有直接用户，可改写为：调用方、维护者、设备侧执行单元或外部系统角色
