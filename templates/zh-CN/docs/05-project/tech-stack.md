# 技术选型

## 用途

记录关键技术选型、备选方案和取舍理由。

> 技术选型不只适用于 Web 技术栈。对于 CLI、桌面程序、嵌入式、库或设备控制软件，同样应记录工具链、运行环境、协议与硬件依赖。

## 建议章节

### ADR 模板

- 决策主题
- 背景
- 备选方案
- 选择结果
- 选择理由
- 影响范围

### 建议分类

- 编程语言 / 运行时 / 编译工具链
- 框架 / 中间件 / 核心库
- 存储 / 通信 / 协议
- 部署环境 / 操作系统 / 发行方式
- 硬件平台 / 芯片 / RTOS / 驱动依赖（如适用）

### 适用范围

- 只记录重要选型，不要把日常实现细节全部塞进来
- 如果项目没有“前端 / 后端”分层，也照样可以按运行环境、边界和关键依赖来组织选型记录
