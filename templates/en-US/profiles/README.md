# Project Type Profiles

Profiles help decide which template docs to enable, merge, or remove for a specific project type. They do not store project facts.

| Profile | Project Type |
|---------|--------------|
| `agent-platform` | agents, tools, skills, memory, orchestration |
| `cli-tool` | command-line tools and local scripts |
| `web-saas` | web apps and SaaS consoles |
| `library-sdk` | libraries, SDKs, plugins, frameworks |
| `software-automation` | UI automation, CLI orchestration, RPA, local workflows |
